# KavaskaFilm

[Сайт KavaskaFilm](https://kavaskakova.github.io/KavaskaFilm/)

Kavaska Film — это бесплатный сайт для поиска и просмотра фильмов. Платформа представляет собой каталог фильмов с обложками и удобной навигацией.
Пользователи могут просматривать каталог, выбирать интересующие фильмы и переходить на сторонние сайты для их просмотра.

Возможности
🎥 Каталог фильмов с обложками.
🖼️ Визуальное представление фильмов.
🆓 Бесплатный доступ к каталогу.
💻 Простой и удобный интерфейс.

Важно: сайт не хранит и не размещает видеофайлы на собственных серверах. Воспроизведение осуществляется на сторонних ресурсах.
